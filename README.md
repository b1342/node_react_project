# 🚀 Node React Project

Full-stack web application built with **Node.js** and **React**.
This project demonstrates a typical architecture where a **Node backend** provides APIs and a **React frontend** handles the user interface.

---

## 📌 Overview

This project combines:

* **Node.js / Express** – Backend server and API
* **React** – Frontend user interface
* **REST API communication** between frontend and backend

The goal is to demonstrate a simple **full-stack architecture** where the backend manages data and the frontend provides an interactive UI.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/b1342/node_react_project.git
cd node_react_project
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Running the Project

Start the backend server:

```bash
npm run server
```

Start the React client:

```bash
npm start
```

Open the app in your browser:

```
http://localhost:3000
```
